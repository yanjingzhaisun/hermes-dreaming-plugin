# 判官标定方法（LLM judge calibration）

适用：给门禁/审核类 LLM 判官（fact 语义审查、冲突分型等）建金标、标定、验收。方法是通用的，不绑特定模型。

## 每对只判一次

判官的单条判决与「哪些样本被送判」的参数（候选阈值、top-k）无关——那些参数只决定送判集合。每个样本送判一次、判决连真实 token usage 落账本；各参数组合的指标从账本离线复算。按「参数网格 × 样本」重复送判会把标定预算放大一个数量级，是纯方法论浪费。

## 金标双人盲标

- 实施者初标后，派看不到初标结果的独立标注者重标（delegate_task 风扇，每批 ~60 条，prompt 只给判定规则与样本，不给初标）。
- 一致才定标；分歧落 uncertain 单列、不进指标分母。
- 实施者、标注者、判官尽量是不同模型/会话——判官不能给自己的标定集打分。

## 挑战集

- 门禁安全性的证明靠「单原子变异挑战集」：对同一事实只改一处（否定/数值/日期/版本/范围/人名），要求判官在这批上「误判为等价 = 0」。这比整体准确率更能证明闸门安全。
- 金标某类稀缺（自然样本里个位数）就人工构造补：从既有样本改写生成该类，标注为人工构造、单独统计——否则该类指标没有分母，验收永远出不来。

## 成本与超时先实测

- 标定预算先跑个位数探针拿单请求真实 token 与耗时，再定总额度报批：带 thinking 的判官实测可达 7k+ token/请求，远超按可见输出文本的估计。
- 交互路径的超时初值不适用于批量判官：按实测耗时分布设超时（均值 ~28s/请求时沿用 10s 会三连熔断）。批量参数（每批组数、批间隔）跟着单请求实测值推导，不拍脑袋。

## 验收分层

- **候选召回与判官指标分开验收**：金标正例必须先被候选生成覆盖，判官才有得判；候选层不达标时判官再准也没用。
- 单向量余弦通道会漏低余弦改写对；本地免费信号（实体共现、FTS）做并集通道能显著补召回，先离线复算验证再加进候选逻辑。
- 标定/留出集按实体连通簇隔离划分，防同一簇样本同时出现在两侧造成泄漏。

## 判官档位不够的表现与换判官探针

- **严格 same 覆盖契约会把弱判官压成「永不说 same」**：same 判决若要求逐字全覆盖引文，能力不够的模型干脆不判 same（预测 same=0、macro-F1 崩盘），校验器的 `same_without_full_coverage` 拒绝数是早期信号。这类失败是保守方向（不误合），但验收永远过不了——别把「安全但无用」当达标。
- **换判官用单变量探针**：同一冻结 prompt、同一校验器、同一分层样本清单（每类都要有足够的类内分母），只换模型。探针规模 ~100 对就够定去留，过了再跑全量标定。同一样本上多模型判决要分键落账本，翻转方向逐对可查。
- 判官模型本身就是变量：语义分类这种判断密集任务，快省档模型可能系统性够不着验收线；探针不过线先换档位，别急着改 prompt——prompt 与模型同时动就归因不清了。

## 冻结计划运行期不可手改

- 带冻结 plan（含 budget_cap、样本清单、hash 自校验）的标定/批处理 harness，**运行中不许外部手改计划文件**——改一个字节就会因 hash 不符冻结拒跑，比「额度不够」更难看的死法。改预算/参数的正解：让执行会话 resume 时带显式修正案标记（编号＋授权来源），由 harness 自己走 amendment 路径重冻结。
- 同理，跑在 harness 外的进度汇报/监控脚本必须读**权威账本**（ledger），别读便利快照文件——快照停更时会报出假停滞，误导用户以为任务死了。

## 思考型判官的墙钟陷阱与指标口径

- **分类类判官先探「关思考」**：思考型大模型（如 qwen3.8-max 默认思考开）单请求 p50 可达 150s+，任何固定墙钟都会大面积超时；同模型 `enable_thinking=false` 后 p50 掉到 ~4s 而分类质量不降（三分类任务实测 macro-F1 0.90 过线）。探针矩阵里「思考开/关」要和模型一样当独立变量测，别默认开着。
- **超时会污染端到端指标，要拆两个口径报**：「有效判决 macro-F1」（只算判出来的）与「端到端 macro-F1」（超时/拒答算判错）必须分列——一个「判出来全对但 60% 超时」的判官是基建问题不是质量问题，修法是调超时/关思考，不是换模型或改 prompt；反之端到端高但有效口径低才是真质量不够。
- **校验器拒答（abstain）是 fail-closed 的漏判，不是误判**：same 判决因覆盖引文不足被拒，生产语义＝不动数据（最多漏一次去重机会），与「把 different 误判成 same」性质完全不同。指标里弃权单列，召回给两个分母口径（含/不含弃权），别把弃权混进精确率分母。

## 样本量上限决定能声称什么

- 零失误下声称精确率 ≥p 需要 n≈3/(1−p) 个有效样本（rule of three：98% 精度要 ~150 个零失误 same 判决）。自然语料里正例可能只有个位数，把「留出集 ≥30 判 same」这种 bar 写死进 AC 会永远过不了——设计 AC 时先估自然正例密度，不够就：人工构造补量（单独统计）、或接受合并证据先进 shadow、把统计认证留给 shadow 期真实数据攒量。别把「证据不够」与「质量不够」混为一谈，两者的下一步完全不同。
